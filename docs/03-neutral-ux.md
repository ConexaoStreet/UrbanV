# Fase 03 — UX neutra

A UI antes do branding usa preto, branco e cinzas funcionais, tipografia de sistema e mídia neutra. Nenhum logo final, campanha, fotografia comercial ou linguagem visual definitiva entra nesta fase.

## Componentes
- Skip link
- Announcement bar
- Header responsivo
- Mega menu/drawer
- Busca com sugestões
- Breadcrumbs
- Product card
- Product grid
- Filtros desktop + bottom sheet mobile
- Seletor de variantes
- Guia de tamanhos
- Sticky add-to-cart mobile
- Drawer de carrinho
- Estados vazio/loading/erro
- Toast/alertas acessíveis
- Footer com políticas
- Consentimento de cookies
- Formulários com erros associados

## Princípios
- alvo de toque confortável
- foco visível e ordem lógica
- nenhuma interação exclusivamente por hover
- redução de movimento respeitada
- conteúdo utilizável a 200% de zoom
- skeletons sem layout shift
- escassez e promoções apenas quando verdadeiras
- checkout sem dark patterns
