# Urban V

Loja virtual de streetwear com catálogo, páginas de produto, login, conta e fluxo de pagamento em front-end.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- JSON para catálogo de produtos

## Estrutura

```text
index.html
produtos.html
produto.html
login.html
conta.html
pagamento.html
products.json
css/
js/
```

## Recursos

- Catálogo de produtos
- Filtros e páginas de produto
- Carrinho
- Área de login/conta
- Interface responsiva
- Animações e elementos interativos

## Execução

Abra `index.html` ou utilize um servidor local para evitar limitações ao carregar arquivos JSON.
